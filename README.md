# KFZ-Service Kaya

Moderne Onepager-Webseite für **KFZ-Service Kaya** - Kfz-Werkstatt in Schwäbisch Gmünd.

Gebaut mit Next.js 14 (App Router), TypeScript und Tailwind CSS. Responsive, SEO-optimiert und mobile-first nach Briefing.

## Lokal starten

```bash
npm install
npm run dev
```

App läuft unter [http://localhost:3000](http://localhost:3000).

## Production-Build

```bash
npm run build
npm run start
```

## Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Inter & Montserrat (next/font/google)
- Strukturierte Daten (Schema.org `AutoRepair`)

## Inhalt

- Hero mit Call-to-Action (Anrufen / Leistungen)
- Trust-Bar
- Leistungen (Wartung, Reparatur, Diagnose, Tuning, Fahrzeughandel)
- Über uns (mit Inhaber Mustafa Kaya)
- Warum KFZ-Service Kaya
- Galerie / Einblicke
- Kontakt mit Google-Maps-Einbindung
- Footer
- Sticky Mobile CTA (Anrufen / Route / E-Mail)
